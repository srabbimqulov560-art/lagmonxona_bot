# Lagmonxona Bot 🍜

A comprehensive Telegram bot built for restaurants to streamline the food ordering process. It provides a seamless experience for customers to browse the menu, build a shopping cart, and check out, while empowering administrators to efficiently receive and manage incoming orders.

## ✨ Key Features
* **Interactive Menu:** Customers can view the complete, categorized restaurant menu directly within Telegram.
* **Shopping Cart System:** Users can easily select items, manage quantities, and review their cart before making a purchase.
* **Checkout & Payment:** Integrated payment workflow allowing customers to securely pay for their orders.
* **Admin Order Management:** Completed orders are instantly forwarded to the admin for review, acceptance, and processing.

## 🛠️ Technologies & Architecture
* **Language:** Python
* **Framework:** Aiogram (Telegram Bot API)
* **Database:** SQLite (`bot.db`)
* **Deployment:** Fully containerized using Docker & Docker Compose.
* **Structure:** Modular architecture with separated `handlers`, `keyboards`, and `core` functionalities.
